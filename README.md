## เทคโนโลยีที่ใช้
Vue 3, Vite, Vue Router, Supabase (ฐานข้อมูล + Auth), Netlify

## วิธีติดตั้งและรัน
1. ติดตั้ง Node.js รุ่น LTS
2. คัดลอก .env.example เป็น .env.local แล้วใส่ค่า VITE_SUPABASE_URL และ VITE_SUPABASE_KEY
3. npm install
4. นำเข้าฐานข้อมูลจากโฟลเดอร์ database/ (รัน schema.sql ใน Supabase SQL Editor)
5. npm run dev แล้วเปิด http://localhost:5173
